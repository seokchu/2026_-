# 07 Sparse-FEMS 분석 상태판 (작성 2026-09-27)

## 이미 입증된 것 (재검증 대상 아님 — 06 이전 산출물)
- 1~6월 대부분은 일 프로파일 복제(증강). 7~9월(76일)이 원본 구간.
- 랜덤 분할은 낙관적. 중복 제거/역중복 가중은 성능을 유의하게 개선하지 않음.
  원본만 학습은 유의하게 나쁨(학습량 손실). → 복제 분석의 역할은 **평가 프로토콜 위생**.
- HGB > persistence. 원본 구간에서 MAE 약 31% 개선.
- is_operating = 생산량>0. 조업 구간 오차 >> 비조업 구간 오차.
  상태 분리는 Ridge 에 크게, HGB 에 작게(state_feature 만) 유효. state_specific 은 비유의.
- 원본 구간 피크 분류는 어렵다. AUC 는 높아 보이나 AP 가 급락(희소성).
- CQR 은 marginal coverage 를 고치지만 순위(ranking)를 개선하지 않고, 피크/조업 조건에서
  conditional coverage 가 붕괴 → Mondrian 필요.
- 높은 피크 recall 은 다량의 오경보를 요구 → 비용 기반 임계 설계 필수.
