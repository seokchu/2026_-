## 사출성형 (injection molding)

### I-1 [DATA STRUCTURE] 전 행이 2배 복제된 shot 쌍

- **왜 특이한가**: 공개 데이터셋에서 "유효 표본이 절반"이라는 사실이 명시되지 않았다. 랜덤 CV는 필연적으로 누출된다.
- **변수**: 24개 공정 변수 전체 / 적용 범위: labeled 2파일 전체
- **강도 강 / 강건 / 추가검증 불필요**
- **운영적 활용**: 벤치마크 신뢰도 감사. "보고된 정확도 중 얼마가 중복 누출인가"의 정량화.
- **방법론**: 그룹 CV, 누출 vs 무누출 성능 갭 보고.
- **계산비용**: 초. **리스크**: 단독으로는 서사가 얇다. 다른 재료와 결합 필요.

### I-2 [DATA STRUCTURE] 환원 불가 라벨 노이즈 (베이즈 오류 하한)
- **근거**: rg3 불량 25건 **전부**가 특성 동일·라벨 상반 짝을 가진다(충돌 pair 25개). cn7은 17건 중 11건(64.7%). RF + pair 그룹 CV rg3 AUC **0.504**. OOF FN 중 충돌 pair 비율 100%, cn7 TP 중 충돌 pair 비율 0%. (`02_mold_duplicate_pair_forensics.csv`, `02_mold_oof_rg3.csv`)

- **강도 강 / 강건 / 추가검증 불필요**
- **운영적 활용**: "이 공정 변수 세트로는 판정이 불가능하다 → 추가 센서/검사 항목이 필요하다"는 투자 근거.
- **방법론**: 중복쌍 기반 베이즈 오류 하한 추정, 라벨 노이즈 하 학습(Natarajan 류), conformal 예측으로 "판정 보류" 구간 설계.
- **계산비용**: 초. **리스크**: 부정적 결론이라 "모델 개발 40점" 배점과 궁합이 나쁘다. 반드시 보완 산출물(보류 정책 등)과 묶어야 한다.

### W-2 [DATA STRUCTURE] 라벨 입도 불일치 (행 로그 vs 일 집계)

### W-3 [PROCESS INTERACTION] 물리 파생변수의 완전 중복

- **강도 강 / 강건**
- **방법론**: 파생변수 중복도 R² 스크리닝을 전처리 표준으로 제안.
- **계산비용**: 초. **리스크**: 다른 데이터셋으로 일반화하려면 재검증 필요.

## 프레스 유압펌프 (hydraulic press)

### P-1 [ANOMALY] 취득경로 지문 누출 — ADC 양자화 격자
- **근거**: outlier 파일의 `AI2_Current`가 전부 1.1920929의 정수배(편차 최대 5.0e-5), normal은 아님(평균 편차 0.2504). 진동 소수점 자릿수 normal 6 / outlier 8. 단일 특성 AUC **0.99993** / 0.99314. (`04_press_acquisition_leakage.csv`, `04_press_single_leak_feature_auc.csv`, `01_press_acquisition_grid_leak.csv`)
- **왜 특이한가**: 물리적으로 무의미한 특성 하나가 라벨을 거의 완벽히 맞힌다. 이 데이터셋의 모든 "고성능 이상탐지" 보고를 무효화한다.
- **강도 강 / 강건 / 추가검증 불필요**
- **운영적 활용**: 배포 전 데이터 위생 점검 항목(양자화 격자·자릿수·타임스탬프 분포 지문).
- **방법론**: 격자 잔차 검정, 문자열 자릿수 분포, 채널별 최소 스텝 비교.
- **계산비용**: 초.
- **검증 완료 (중요)**: 두 파일을 공통 거친 격자(진동 1e-3 / 전류 2.0)로 재양자화해 지문을 소멸시킨 뒤에도 물리 특성만으로 AUC **1.000**이 유지된다(`04b_press_baseline_after_leak_removal.csv`). → **누출은 높은 성능의 원인이 아니다.** 누출과 물리 신호가 독립적으로 각각 완벽히 분리한다. 이 재료의 가치는 '성능 설명'이 아니라 '데이터 위생 진단' 자체다.
- **리스크**: 남는 교란(날짜 07-12 vs 07-17, 이상 사건 1건)은 제거 불가능하다.

### P-2 [SENSOR RELATIONSHIP] 전류 이상은 진폭 무변화·스펙트럼 전용
- **근거**: `AI2_Current_std` AUC 0.378, p=**0.121**(차이 없음). 반면 spec_entropy 0.911→2.133(AUC 1.000), bandhigh(>3Hz) 0.0006→0.2102(AUC 1.000), acf1 0.928→0.523(AUC 0.000). (`04_press_window_feature_separation.csv`)
- **왜 특이한가**: RMS/피크 기반 전통 진단이 실패하는 구체적 사례를 같은 데이터 안에서 대조 제시할 수 있다.
- **강도 강 / 조건부(이상 사건 1건) / 추가검증 필요**
- **운영적 활용**: 채널별로 다른 진단 지표를 쓰라는 지침.
- **방법론**: 진폭/형상/스펙트럼 특성군 분리 성능 비교(`04_press_baseline_by_feature_family.csv`: amplitude AUC 0.936–0.956 vs shape/spectral 1.000).
- **계산비용**: 초. **리스크**: P-1 누출과 같은 채널이므로 **누출과 신호를 분리해 제시해야** 한다.

### P-3 [DATA STRUCTURE] 실제 관측 단위는 5초 버스트
- **근거**: 최대 50샘플 버스트, 정상 599개 / 이상 21개, 버스트 사이 공백 1–16.6초, duty cycle 0.43 / 0.36. 벽시계 77분 중 실취득 43%. (`04_press_sampling_geometry.csv`)

- **강도 강 / 강건**
- **방법론**: 버스트 단위 그룹 CV.
- **계산비용**: 초.

### P-4 [ANOMALY] 10 Hz 샘플링 — 에일리어싱 + Nyquist 한계
- **근거**: fs = 10 Hz, Nyquist 5 Hz. 정상 전류는 주기 1.8s(0.555 Hz) 거의 완전 정현파(lag1 acf 0.902, 첨도 −0.86). Matrix-Profile discord 중위: 정상 전류 **0.152** vs 이상 3.644(24.0×), 진동은 0.92× / 1.41×. (`04_press_matrix_profile_ratio.csv`)
- **왜 특이한가**: "진동 데이터니 FFT로 베어링 주파수를 보자"는 기본 발상이 원리적으로 불가능함을 수치로 증명한다.
- **강도 강 / 강건(에일리어싱 원인은 가설)**
- **방법론**: Nyquist 논증 + discord 자기유사도.
- **계산비용**: 분(전 채널 MP 계산 약 1–2분). **리스크**: 60 Hz 계통 주파수 가정은 미확인.

### P-5 [SENSOR RELATIONSHIP] 센서간 상관 부호 반전
- **근거**: corr(AI0, AI1) 정상 파일 +0.368 → 이상 파일 −0.381. 결합 특성 4개만으로 logreg AUC 0.850 / RF 0.968.
- **강도 중 / 조건부 / 추가검증 필요**
- **계산비용**: 초. **리스크**: 이상 사건 1건에 근거.

### P-6 [UNCERTAINTY] 비지도 + 오경보 예산으로 지도학습 불필요
- **근거**: 정상만 학습한 Mahalanobis가 1% 오경보 예산에서 이상 재현율 **1.000**, AUC 1.000 (누출 채널 AI2 제외). IsolationForest 동일. 오경보 5개 윈도는 전부 기록 초반 26분 안, `AI1_Vibration_std`가 중위의 1.4–2.1배. (`04_press_false_alarm_budget.csv`, `04_press_false_alarm_windows.csv`)

- **운영적 활용**: 라벨 없이 배포 가능한 경보 체계 + 기동 과도상태 경보 억제 규칙.
- **계산비용**: 초. **리스크**: 오경보 표본 5개 → 억제 규칙의 통계적 근거가 약하다.

### E-2 [EARLY WARNING] p99 피크의 1시간 선행 램프

### E-3 [INSPECTION/EARLY WARNING] 1시간 선행 피크 분류 성능

### E-4 [OPTIMIZATION] "같은 생산량, 다른 피크"의 정체는 스케줄이 아니라 기온
