# 26. 공식 과제 예측 정의 검증 — Forecast Horizon Alignment

작성: 2026-10-05

목적: Baseline v1.1의 `t+15/30/45/60분` 다중시점 예측이 KAMP 자원 최적화 데이터셋의 공식 목적과 어긋나는지 확인하고,
3자 자료에서 발견된 “전날 16시에 다음 날 96개 15분 구간을 예측”이라는 서술의 근거 여부를 정리한다.

## 1. 결론

### 최종 판정

**현재 Baseline v1.1의 t+15/30/45/60분 구조는 유지한다. Horizon 수정은 필요하지 않다.**

다만 표현은 정확히 구분한다.

- **공식 가이드북이 직접 예시로 구현한 것**
  - 15분 간격 최대수요전력의 사전 예측
  - Random Forest 실습에서 현재 시점의 **다음 15분 전력**을 타깃으로 하는 1-step 예측
  - RNN 실습에서 시간 인덱스 기준 `n_times_advance=1`의 1-step-ahead 예측
- **우리 프로젝트가 확장한 것**
  - 동일한 15분 시계열을 기준으로 `t+15/30/45/60분`을 동시에 direct forecasting
  - h60 조기경보 → h15 확인 정책

즉, **15/30/45/60분 다중 horizon이 공식 의무사항이라고 주장하지 않는다.**
공식 문서의 “사전 예측”과 “다음 시점 예측”을 운영 목적에 맞게 1시간 범위의 multi-horizon으로 확장한 설계라고 설명한다.

## 2. 2026 대회 공고에서 확인되는 범위

2026년 제6회 K-인공지능 제조데이터 분석 경진대회의 공개 공고는
KAMP 제조AI 데이터셋을 활용해 중소 제조기업의 공통문제를 해결·개선하는 AI 분석모델 개발을 요구한다.

공개 공고에서 확인되는 예시는 장비이상 조기탐지, 품질 이상탐지/진단, 공정운영 최적화 등이며,
**“전날 16시 기준으로 익일 96개 15분 구간을 일괄 예측해야 한다”는 고정 horizon/제출 형식은 확인되지 않았다.**

확인 URL:
- https://www.kamp-ai.kr/contestMain
- https://www.ggcrf.kr/view/contest/541637
- https://www.co-worker.co.kr/Contest/contest_view?idx=15464

따라서 공개된 2026 대회 공고만으로 day-ahead 96-step 의무를 주장할 근거는 없다.

## 3. KAMP 공식 「자원 최적화 AI 데이터셋 분석실습 가이드북」 근거

사용 문서:
`Guidebook_자원 최적화 AI 데이터셋.pdf`

### 3.1 데이터의 기본 시간 구조

가이드북은 최대수요전력을 **15분 단위**로 계산·수집하며, 사전에 최대수요전력을 예측하는 모델을 만드는 것을 분석 목표로 둔다.
또한 원본 한 행의 `15분/30분/45분/60분` 열은 각각 한 시간 내의
0~15 / 15~30 / 30~45 / 45~60분 구간을 의미한다.

**주의:** 이 네 열의 이름 자체가 `t+15/t+30/t+45/t+60` forecast horizon을 의미하는 것은 아니다.
원본 데이터의 한 시간 내부 4개 관측 구간이다.

### 3.2 Random Forest 실습은 명시적인 “다음 15분” 예측

가이드북은 6,168행 × 4개 구간을 24,672개의 15분 시계열로 재구성한 뒤,
`y_labels`를 현재 인덱스의 **다음 전기 사용량**으로 정의한다.

문서의 예:
- 현재 입력: 2021-01-01 11:00
- 정답 `y_labels`: 2021-01-01 11:15

즉 공식 실습에 **15분 ahead next-step forecasting이 명시적으로 존재한다.**

### 3.3 RNN 실습 역시 day-ahead 96-step 고정이 아니다

RNN 예시는 `Peak Consumption in 15 minute` 시계열에 대해:
- 과거 window = 168
- `n_times_advance = 1`

을 사용한다.

여기서는 인덱스가 1시간 단위이므로 이 예시는 해당 subseries의 **1시간 ahead** 실습이다.
9월 1~14일의 336개 포인트를 테스트 구간으로 사용하지만,
“전날 특정 시각에 다음 날 96개를 한 번에 예측”하는 문제로 정의되어 있지 않다.

## 4. “전날 16시 → 익일 96개” 서술 판정

3자 저장소/검색 요약에서 발견된
“전날 16시에 다음 날 96개 15분 구간 예측” 서술은
현재 확보된 공식 가이드북 및 2026 공개 대회 공고에서 근거를 찾지 못했다.

### 판정

**UNSUPPORTED THIRD-PARTY INTERPRETATION**

- 공식 요구사항으로 사용 금지
- 발표/보고서에서 언급할 필요 없음
- 이 주장 때문에 현재 forecasting horizon을 변경하지 않음

추후 주최측이 별도의 비공개/로그인 전용 문제지에서 day-ahead 규칙을 명시했다는 직접 자료가 확보되는 경우에만 재검토한다.

## 5. Baseline v1.1과의 정합성

현재 코드:
- 15분 long 시계열 구성
- `y_h1 = kw.shift(-1)`
- `y_h2 = kw.shift(-2)`
- `y_h3 = kw.shift(-3)`
- `y_h4 = kw.shift(-4)`

따라서 각각:
- h15 = 15분 뒤
- h30 = 30분 뒤
- h45 = 45분 뒤
- h60 = 60분 뒤

를 예측한다.

이는 공식 RF 실습의 next-15-minute forecasting을 포함하면서,
현장 대응시간 확보를 위해 1시간 범위까지 확장한 구조다.

### 최종 설명 문장

> KAMP 공식 가이드북은 15분 단위 최대수요전력의 사전 예측을 목표로 하며, Random Forest 예제에서는 현재 시점의 다음 15분 전력을 직접 예측한다. 본 프로젝트는 이를 운영 관점에서 15·30·45·60분 다중시점 예측으로 확장해, 장기 조기경보와 단기 재확인을 결합한다.

## 6. 이번 검증에 따른 작업 결정

| 단계 | 결정 |
|---|---|
| ① 공식 예측 정의 확인 | **완료** |
| ② forecasting horizon 수정 | **불필요 — 현행 h15/h30/h45/h60 유지** |
| ③ baseline 재실행 | horizon 변경이 없으므로 이 사유만으로는 불필요 |
| ④ 제출 패키징 | 공식 정합성 리스크를 해소한 상태로 진행 가능 |

## 7. 남아 있는 별도 주의사항

- 공식 가이드북의 `15분/30분/45분/60분` 열을 우리 multi-horizon target과 동일 개념이라고 쓰지 않는다.
- “day-ahead 96-step”을 공식 요구사항처럼 쓰지 않는다.
- 비용/요금 관련 공식 단위와 최신 과금 규칙은 forecast horizon과 별개로 추가 확인 대상이다.
- 공식 대회 페이지에 로그인 후 별도 문제지/FAQ가 존재한다면 그 문서가 최상위 근거가 된다.
