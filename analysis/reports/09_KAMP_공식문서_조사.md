# KAMP 전력 데이터셋 공식 설명서 조사 결과

> 조사일 2026-09-26. **결론: 공식 변수 정의서를 확보하지 못했다.** 아래는 확인된 사실, 확인 실패한 경로, 그리고 사용자가 직접 받을 수 있는 정확한 절차다.

---

## 1. 요약

| 확인 요청 항목 | 공식 근거 확보 | 현재 상태 |
|---|---|---|
| 15분/30분/45분/60분 이 kW 인가 kWh 인가 | **실패** | 미확인. 발표에서 단정하면 안 됨 |
| 생산량의 실제 단위 | **실패** | 미확인 |
| 공장인원이 정확히 무엇인가 | **실패** | 미확인. 우리 측정값(생산량과 spearman 0.994)만 근거 |
| okm_augumented_2021 의 공식 augmentation 방식 | **실패** | 미확인. 우리 측정값(일 96칸 완전일치 복제)만 근거 |

**중요**: 조사 과정에서 자동 요약 도구가 한 PDF에 대해 전력 관련 내용을 생성했으나, PDF 원문을 직접 텍스트 추출해 대조한 결과 **그 문서는 전력 데이터셋이 아니라 MCT 공구관리 데이터셋**이었다. 해당 요약은 근거에서 폐기했다. 본 문서에는 원문을 직접 확인한 내용만 싣는다.

## 2. 확인된 사실 (원문 대조 완료)

### 2.1 공식 과제명
`okm_augumented_2021.csv` 는 제6회 K-인공지능 제조데이터 분석 경진대회
**과제 ⑤ "제조 생산데이터 기반 전력사용량 예측 및 최대피크 위험조건 분석"** 의 데이터로 배포된다.
KAMP 카탈로그상 분류는 **「정밀가공 부문 자원최적화 AI 데이터셋」** 계열이다.

### 2.2 KAMP 가이드북 공개 경로는 실재한다
`https://www.kamp-ai.kr/mnt/dataset/<숫자ID>.pdf` 형식의 「AI 데이터셋 분석실습 가이드북」이 로그인 없이 받아진다. 실제로 내려받아 표지를 확인한 것:

| ID | 표지 제목 | 쪽수 | 전력 관련 |
|---|---|---|---|
| 374950177 | 「공정운영 최적화 AI 데이터셋」 분석실습 가이드북 | 73 | `전력` 1회, `수요전력` 1회 (본문 언급 수준) |
| 458329292 | 「생산계획 최적화 AI 데이터셋」 분석실습 가이드북 | 68 | 없음 |
| 97567180 | 「주조 품질보증 AI 데이터셋」 분석실습 가이드북 | 78 | 없음 |

→ **자원최적화(전력) 가이드북의 ID 는 공개 검색으로 노출되지 않는다.**

### 2.3 카탈로그 페이지는 비공개로 전환되어 있다
- 구 경로 `https://www.kamp-ai.kr/front/dataset/AiData.jsp?...` → **404**
- 현 경로 `https://www.kamp-ai.kr/aidataList` → 200 이지만 목록이 **클라이언트 렌더링**이고, `AI_SEARCH=자원` / `AI_SEARCH=전력` POST 결과가 동일한 빈 목록이다(로그인 필요).
- 데이터셋 상세는 `/aidataDetail` + `DATASET_SEQ` 파라미터 구조이나 SEQ 값이 비로그인 응답에 없다.

### 2.4 외부 자료의 진술 (2차 자료 — 공식 아님)
- 한 참가자 저장소(`zongseung/manufacture`)가 **독립적으로 동일한 결론**에 도달해 있다: 전력 96칸이 소수점까지 같은 날을 증강 복사로 판정하고, `공장인원` 을 "누수 열(leakage column)"로 분류해 제거했다.
  → 우리 발견의 **독립 재현 증거**로는 쓸 수 있으나, **공식 정의의 근거로는 쓸 수 없다.**
- 한 참가자 저장소(`chosunje/kamp-contest`)는 `okm_augumented_2021.csv` 를 "원본 데이터(수정하지 않음)"로만 표기하고 컬럼 정의를 싣지 않는다.
- KAMP 안내 문서에 따르면 각 데이터셋에는 "원시 데이터, 전처리된 학습용 데이터, **상세한 데이터 명세서**, 활용 가이드북"이 함께 제공되며, **명세서에는 각 변수의 의미·측정 방법·단위·정상 범위가 기재**된다. 즉 **요청한 정보는 존재하지만 회원 로그인 뒤에 있다.**

## 3. 사용자가 직접 받는 절차 (이게 가장 빠른 길)

1. `https://www.kamp-ai.kr` 회원가입·로그인 (중소기업 재직 여부 무관, 무료)
2. 상단 **제조AI데이터셋** → 목록에서 **「정밀가공 부문 자원최적화 AI 데이터셋」** (또는 검색창에 `자원최적화`)
3. 상세 페이지 첨부에서 다음 3종을 모두 받을 것
   - **데이터 명세서** ← 15분/30분/45분/60분 단위, 생산량 단위, 공장인원 정의가 여기에 있다
   - **분석실습 가이드북 (PDF)**
   - 원시 데이터 / 학습용 데이터
4. 받은 뒤 확인할 최소 4개 항목 (발표 서사의 전제)
   - [ ] 전력 4개 컬럼의 **척도·단위** 란: `kW` 인가 `kWh` 인가
   - [ ] 15분/30분/45분/60분이 **순시값**인가 **해당 15분 구간의 평균수요**인가 (최대수요전력 요금 서사는 후자를 전제한다)
   - [ ] `생산량` 의 단위 (ea / kg / EA·shot 등)
   - [ ] `공장인원` 의 **측정 방법**: 실인원인지, 생산량 기반 환산 지표인지
   - [ ] 증강(augmentation) 방식이 명세서/가이드북에 기술되어 있는지

> 로그인 계정이 생기면 알려 달라. 명세서 PDF 를 받아 주면 텍스트를 추출해 우리 측정값과 한 줄씩 대조한 표를 만들겠다.

## 4. 명세서를 못 구한 상태에서 발표할 때의 안전한 표현

우리 분석이 **직접 측정한 사실**만으로 말할 수 있는 범위는 다음과 같다. 이 표현은 명세서 없이도 방어 가능하다.

| 주제 | 안전한 표현 | 피해야 할 표현 |
|---|---|---|
| 전력 단위 | "15분 간격으로 기록된 전력 지표(문서상 단위 미확인). 본 분석은 단위를 특정하지 않고 상대값으로만 다뤘다." | "15분 수요전력(kW)이므로 최대수요 요금이 …" |
| 요금 서사 | "15분 간격이라는 **기록 구조**는 국내 최대수요전력 산정 단위(15분)와 일치한다. 단위가 확정되면 요금 절감액 산정이 가능하다." | "최대수요전력 요금을 X원 절감한다" |
| 생산량 | "생산량(단위 미확인). 0 여부가 조업/비조업을 가르는 지표로 작동한다." | "생산량 1개당 전력 원단위는 …" |
| 공장인원 | "`공장인원`은 **본 데이터에서** 생산량과 spearman 0.994 로, 독립적인 인력 정보로 사용할 수 없다. 공식 정의는 미확인이므로 실인원인지 환산지표인지는 단정하지 않는다." | "공장인원은 생산량으로 환산된 파생변수다" |
| 증강 | "**본 데이터에서** 257일 중 160일의 일 단위 전력 프로파일 96칸이 다른 날과 완전히 일치한다. 공식 증강 방식은 문서로 확인하지 못했다." | "KAMP가 day-of-month 복사 방식으로 증강했다" |

**[해석]** 사실 이 제약 자체가 발표 재료가 된다. "제공 문서에 단위가 없어 요금 환산을 보류했고, 대신 단위 불변 지표(상대 피크, 포착률·오경보)로 설계했다"는 서술은 데이터 진단 15점·현장 적용성 10점에서 감점이 아니라 가점 요인이다.
