## 1. 사용한 외부데이터 (Category A: 공공·전이 가능)

`07N_external_data_sources.csv` 에 출처·URL·취득일·라이선스·기간·변수·예측시점 가용성·전처리·조인키·결측을 모두 기록했다.

| 데이터 | 출처 | 라이선스 | 예측시점 가용 | 비고 |
|---|---|---|---|---|
| 한국 공휴일·근무일 | python `holidays` 0.83 (KR) | MIT | 예(사전 확정) | is_holiday, is_workday, is_bridge_day, 연휴 길이, 다음 비근무일까지 일수 |
| 시간별 기상 관측 | NOAA NCEI ISD global-hourly | 미국 정부 공개(제한 없음) | 예(관측값) | 기온·이슬점·기압·풍속·시정·운고 + 파생 |
| 태양기하 | 천문 계산(다운로드 없음) | 해당 없음 | 예(결정론적) | 태양고도, 주야, 일조시간 |
| 요금 시간대 구조 | 한전 산업용 계절·부하시간대 구분 | 공개 요금표의 구분만 사용 | 예(사전 공표) | `tariff_season`, `tariff_load_zone`(light/mid/peak). **금액(KRW) 미사용** |

- 미래 기상 **예보는 사용하지 않았다**. 재현 가능한 과거 예보 아카이브를 확보하지 못했기 때문이다(누수 위험 회피).
- ISD 시간 공백은 **직전 관측 유지(ffill, 최대 6시간)** 로만 메웠다. 미래 관측을 쓰지 않는다.
  결측률 40.2% → 1.7% (`07N_external_weather_coverage.csv`).

### 1.1 부수 발견 — KAMP 공장 위치 추정
**[사실]** KAMP 기온 열과 국내 10개 ISD 관측소 시간별 기온의 일치도(`07N_external_station_match.csv`):
울산 pearson **0.997** / MAE **0.40℃** / bias 0.004, 2위 포항 0.985 / 1.21℃, 부산 0.985 / 1.31℃, 서울 0.944 / 3.00℃.
**[해석]** KAMP 자원최적화 데이터의 기상 열은 **울산 인근 관측 기반일 가능성이 매우 높다**.
**[주의]** 공식 문서로 확인된 사실이 아니다. 위치는 데이터셋 문서에 기재되어 있지 않다(09 보고서).
**[해석]** 이 추정의 실질적 함의: 외부 기상을 붙여도 **KAMP 가 이미 같은 관측을 담고 있다**. 중복 정보다.

### 1.2 Category B (타 공장 데이터) — 미수행
전이학습용 공개 산업 전력/설비 데이터셋을 무인증·재현 가능·재배포 허용 조건으로 확보하지 못했다.
E4(전이표현)는 **미수행으로 명시**한다. 결과를 추정으로 채우지 않는다.

### 3.1 예측 정확도 — `07N_external_ablation_forecast.csv`, `07N_external_ablation_bootstrap.csv`

| 30분 | 7.262 | 7.247 | 7.189 | 7.397 | **+0.135** CI [0.065, 0.204] — 유의하게 악화 |

**[사실]** 방향이 horizon 마다 뒤집힌다. 60분에서 −6.4%(유의) 개선, 15·30분에서는 유의한 악화.
**[사실]** 공휴일 정보(E1)만으로도 60분 MAE −0.277 CI [−0.380, −0.164] 개선이 나온다.
**[해석]** 외부데이터의 기여는 **장기 horizon 의 달력·계절 구조**에 국한된다. 단기(15·30분)는 최근 전력이력이
이미 지배적이어서 특성이 늘면 오히려 손해다(용량 분산).

### 3.2 피크 선별력
**[사실]** 피크 AP: E0 0.367 → E3 0.378 (60분), 15분은 0.587 → 0.582, 45분은 0.375 → 0.328.
일 10건 예산의 이벤트 포착률: 60분 0.789 → 0.810, 15분 0.939 → 0.946.
**[해석]** 피크 선별력 개선은 잡음 수준이다. 외부데이터는 피크를 **더 잘 찾아주지 않는다**.

### 3.4 난조건 — `07N_external_hard_conditions.csv`
**[사실]** 모델 불일치 상위 20% 조건의 MAE 비: E0 1.83 → E1 1.66 → E2 1.51 → E3 **1.29**.
불일치 상위 20% ∩ 비조업: 3.43 → **1.63**.
**[사실]** 트리 기반 승격 난조건 수: E0 2개 → E1~E3 **1개**. 0개가 되지는 않았다.
**[사실]** 반면 문맥 기반 조건은 그대로다. |ramp| 상위 20% MAE 비 1.05 → 1.10, 전환 레짐 1.02 → 1.06.
**[해석]** 외부데이터가 완화한 것은 **모델 간 의견이 갈리는(=선형/비선형 외삽이 어려운) 구간**이지,
**부하가 급변하는 물리적 구간**이 아니다. 난조건은 사라지지 않았다.

## 4. 판정 — `07N_external_decision.csv`

사전에 명시한 규칙:
- CASE1: LOW/OOD −50% 이상 **그리고** 피크 coverage +0.05 이상 **그리고** 전환 MAE −20% 이상
- CASE2: MAE −2% 또는 LOW/OOD −10% 또는 전환 MAE −5%
- CASE3: 그 미만

측정값: MAE(60분) **−6.36%**, LOW/OOD **−0.49%**, 피크 coverage **−0.021**, 전환 MAE **+0.38%**.

### → **CASE 2 — 부분 개선, 신뢰도·난조건 문제 잔존**

1. **[사실]** 외부 공공데이터는 장기 horizon 평균 정확도를 유의하게(−6.4%) 개선한다. 배제할 이유가 없다.
2. **[사실]** 그러나 LOW/OOD 빈도, 피크 구간 coverage, 전환구간 오차는 **개선되지 않았다**(일부는 악화).
3. **[해석]** 따라서 **“외부 공공데이터를 붙이면 저계측 문제가 사라진다”는 반론은 데이터로 성립하지 않는다.**
   남은 실패는 공개데이터로 대체되지 않는 **공장 내부 관측(설비 ON/OFF, 공정 단계, 셋업/교체, 제품·LOT)** 부재와
   더 잘 부합한다(17 보고서 §5 의 A/B 구분과 같은 결론).
4. **[주의]** 이 결론은 **본 데이터셋 1곳, 2021년 1년**에 대한 것이다. 다른 공장에 자동 일반화하지 않는다.
5. **[주의]** 기상 외부데이터의 기여가 작은 이유 중 하나는 **KAMP 가 이미 같은 지역 기상을 담고 있어서**다(§1.1).
   기상 열이 없는 공장이라면 외부 기상의 가치는 지금 측정값보다 클 수 있다. **[가설]**

## 5. 주제에 대한 함의
- 현재 주제의 전제(“공장 전체 집계정보는 있으나 설비·공정 상세 관측이 부족”)는 **유지된다**.
- 단, 발표에서는 반드시 **외부데이터를 넣고도 남는 문제**로 표현해야 한다.
  “외부데이터를 안 써서 어렵다”가 아니라 “외부 공공데이터를 다 넣어도 LOW/OOD·전환·피크 coverage 는 그대로였다”가 정확한 주장이다.
- E4(타 공장 전이)는 미수행이므로 “전이학습으로도 안 된다”는 주장은 **하지 않는다**.
