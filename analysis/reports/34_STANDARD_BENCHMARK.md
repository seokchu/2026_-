작성 2026-10-08. 수치는 `analysis/tables/34_*.csv` 에서 생성.
재현: `python3 analysis/final_baseline/v4_standard_benchmark.py`

## 0. 왜 다시 하는가

이전 보고서들은 우리가 만든 비교축(A0~A5 점진 변형, C0~C8 경보 후보, 무편향 오라클 F1,
사건 recall, OOD 패널티 비율)을 앞세웠다. 그 축들은 내부 의사결정에는 쓸모가 있지만
**외부 독자가 "이게 잘하는 건가"를 판단할 기준이 되지 못한다.**

이번에는 순서를 뒤집는다. **교과서·실무에서 통용되는 모델과 지표로 먼저 비교하고,**
고유 분석은 그 뒤에 부가로 붙인다.

## 1. 쓴 모델 — 표준만

**회귀 15종** · Naive(직전값) / Seasonal naive(24시간 전) / Linear Regression / Ridge / Lasso /
ElasticNet / k-NN(k=10) / SVR(RBF) / Decision Tree / Random Forest / Extra Trees /
Gradient Boosting / HistGradientBoosting / MLP(64,32) / **제출 모델(HistGBM + 극단가중)**

**분류 13종** · Majority class(전부 정상) / Naive rule(현재값>임계) / Logistic Regression /
Gaussian Naive Bayes / k-NN(k=10) / SVM(RBF) / Decision Tree / Random Forest / Extra Trees /
Extra Trees+클래스가중 / Gradient Boosting / HistGradientBoosting / MLP(64,32)

전부 동일한 특성집합·동일한 rolling-origin 분할·동일한 잔차 타깃을 쓴다.
SVR/SVM 만 O(n²) 때문에 학습표본을 5,000행으로 제한했다(명시).

## 2. 쓴 지표 — 표준만

| 과제 | 지표 |
|---|---|
| 수치 예측 | MAE · RMSE · MAPE · sMAPE · **MASE** · R² |
| 이진 경보 | Accuracy · Precision · Recall · Specificity · Balanced Accuracy · **F1** · **MCC** · ROC-AUC · PR-AUC · Brier · Log-loss |

MASE 는 학습구간의 Seasonal naive(24시간) 평균절대오차로 나눈 값이다. 단위에 의존하지 않아
다른 공장·다른 데이터와 직접 비교할 수 있다. 1 미만이면 "24시간 전 값을 그대로 쓰는 것보다 낫다".

## 5. 선정

**수치 예측 — 사전 선언 규칙:** 전체 MAE 와 고사용량 MAE 가 **둘 다** 악화되지 않을 때만 교체.

Extra Trees 는 전체 MAE 가 유의하게 낮지만(h60 −0.786 kw, 95% CI [−1.007, −0.578])
고사용량 구간 MAE 는 유의하게 높다(h45 +0.714 CI [0.043, 1.395], h60 +1.237 CI [0.515, 1.911]).
→ **교체하지 않았다.** HistGBM + 극단가중 유지.

**경보 — Random Forest 채택.** F1 0.512 / MCC 0.510.
생산 구성(외부 달력·기상 특성 포함)에서는 **F1 0.478 (h60) / 0.533 (h15)**.
두 수치의 차이는 행집합(공통 특성 기준 23,980행 vs 생산 23,548행)에서 온다.

**[사실] isotonic 보정은 채택하지 않았다.** RandomForest 400그루의 확률은 이미 충분히 보정되어
있어, CAL isotonic 을 거치면 Brier 가 **0.0477 → 0.0520 으로 악화**된다(ECE 는 0.0490 → 0.0489 로 동일).
F1 도 0.4784 → 0.4777 로 차이가 없다. 보정을 적용한 결과를 표에 함께 남기고 쓰지 않는다.
이전 라운드에서 HistGBM 을 썼을 때는 isotonic 이 Brier 를 개선했다(0.0557 → 0.0498). 모델이 바뀌면 결론도 바뀐다.

## 6. 그래서 이 모델은 잘하는 편인가

| 기준 | 값 | 비교 대상 |
|---|---:|---|
| MASE | **0.215** | 1.0 = 24시간 전 값 그대로. 0.46 = 직전값 그대로 |
| MAPE | **11.30%** | 산업 단기 부하예측 통상 보고 범위와 비교 가능한 형태 |
| R² | **0.958** | — |
| 경보 F1 | **0.512** | Naive rule 0.327 · Majority 0.000 · 무편향 상한 0.693 |
| 경보 MCC | **0.510** | 0 = 무작위 |

**[해석]** 수치 예측은 표준 지표 기준으로 견고하다(MASE 0.215, R² 0.958).
**경보는 그렇지 않다.** F1 0.512 는 단순 규칙보다 확실히 낫지만
같은 오차 크기에서 편향만 없으면 0.693 이 가능하므로 **상한의 74% 지점**이다.
좋다고 쓰지 않는다.

## 7. 주장 불가

- 다른 논문·보고서의 MAPE 와 직접 비교하는 것 — 대상 공장·부하 규모·호라이즌이 다르면 비교 불가.
- ROC-AUC 0.934 를 성능 근거로 쓰는 것.
- Majority class 정확도 0.943 을 "기준선"으로 제시하는 것 — 경보를 하나도 내지 않는 모델이다.
- SVR/SVM 결과를 전체 표본 기준으로 읽는 것 — 학습표본 5,000행으로 제한했다.
