## 요구된 15개 질문에 대한 직답

**1. 의미 있는 정보-성능 트레이드오프가 존재하는가?**
**부분적으로. 계단이 하나뿐이다.** 수요이력만(L0) 남기면 60분 MAE 12.71, 달력을 더하면 7.43
(−41%, paired bootstrap 유의). 그 뒤로 날씨·생산·잠재문맥은 0.1~0.3 kw, 대부분 비유의.

**2. 허용 가능한 예측을 위한 최소 실데이터 정보집합은?**
**L1 = 집계 수요 이력 + 달력/시각.** 모든 구간·horizon 에서 달성가능 개선분의 90% 이상,
15분 horizon 에서는 99.6% 를 확보한다. 추가 계측 0.

**3. 어떤 문맥이 객관적으로 어려운가?**
50개 후보 중 3중 필터(효과크기·지원·폴드 재현성)를 통과한 4개. 전부 `disagreement`(HGB vs Ridge
예측 불일치) 축을 포함한다. 최악은 `disagreement>21 AND lat_dwell>23.5` → MAE 31.55 = 전체의 3.51배.
두 번째 축은 **비조업 + 고불일치**(MAE 23.95, 2.66배) — 즉 *정지 상태가 아니라 정지/기동 전환*이다.

**4. 어떤 난조건이 정보 제한형인가?**
**없다.** 승격 4개 모두 정보를 추가하면 MAE 비가 **커진다**(1.44배 → 3.51배). 정보 추가의 이득은
쉬운 구간에 몰린다. H3 기각.

**5. NILM 유사 잠재문맥이 실제로 도움이 되는가?**
**아니다(예측 모듈로서 REJECT).** 상태는 매우 안정적(시드 ARI 1.00)이고 해석 가능하지만,
4개 horizon 중 1개만 유의 개선·1개 유의 악화, 증강구간 h60 에서 MAE 8.74 → 14.03 대형 악화.
서술/진단 보조로만 남긴다. 장비 단위 진실이 없으므로 '분해'라 부르지 않는다.

**6. SR 이 실제로 도움이 되는가?**
**OPTIONAL.** 잔차식 순위력은 HGB 보다 낮고(AUC 0.615 vs 0.682), 불일치 신호는 Ridge 불일치보다
좋지만(0.724 vs 0.675) 무료 대안 CQR 구간폭(0.733)을 못 이긴다. 남는 가치는 설명 문장 하나:
`expected_abs_error ≈ sqrt(2·sqrt(kw) + sqrt(prod_diff))` (폴드 간 성격 재현, 변수 선택은 불안정).

**7. 최선의 신뢰도 추정 방법은?**
**CQR 예측구간의 폭.** 학습 메타모델 전부를 이긴다(AUC 0.733/spearman 0.559 vs HGB 0.685/0.318).
선형 메타모델은 완전 실패(spearman ≈ 0). **추가 모델 학습이 필요 없다** — 저계측 시스템에 최적.

**8. 신뢰도로 자동화 등급을 가를 수 있는가?**
**가를 수 있다. 다만 결과가 설계를 뒤집는다.** 밴드 MAE 3.84/8.92/15.31/18.23 완전 단조, LOW/HIGH 4.0배,
OOD 에서 coverage 0.735 붕괴. 그러나 `AUTO`(고신뢰+고피크위험)는 4표본(0.1%)뿐 —
**수요가 높으면 구간이 넓어 신뢰도가 HIGH 가 될 수 없다.** 따라서 피크 국면은 자동개입이 아니라
`ADVISE`(5.9% 비중, 피크 유병률 62.7%)로 보낸다. 자동화 불가 비중 19.1% 는 임계와 무관하게 고정.

**9. FP/FN 비용비에 따라 최적 경보 정책은 어떻게 변하는가?**
최적 임계 분위가 **0.91(비용비 1) → 0.65(비용비 100)** 로 이동한다. 비용비 5에서 포착률 0.909·
정밀도 0.550·일 경보 18.2회, 비용비 10에서 0.962·0.461·23.0회. **고정 임계를 제시할 수 없다.**

**10. 한계가치가 가장 높은 정보군은?**
달력(ΔMAE −4.07, −37.0%) ≫ 생산(−0.16) ≈ 날씨(+0.03) ≈ 잠재문맥(+0.04). 단 **피크 AP 에서는
생산정보가 유일하게 일관된 양의 기여**(+0.02~+0.09).

**11. Progressive Instrumentation / Sensor-on-Demand 는 방어 가능한가?**
**원래 근거로는 아니다. 근거를 바꾸면 가능하다.** "정확도를 올리려고 센서를 달자"는 H3 기각으로
무효. 살아남는 주장: 시스템이 **"현재 정보로 설명 불가"를 정확히 탐지한다**(LOW 밴드 MAE 4.0배,
OOD coverage 붕괴). 그것이 계측 요구의 트리거이고, 효과 검증은 가상공장 영역이다.

**12. 제거해야 할 아이디어는?**
- NILM 유사 잠재문맥을 **예측 특성**으로 넣는 것 (H4 기각)
- SR 을 주 예측기 또는 주 신뢰도 모델로 세우는 것 (H5 OPTIONAL)
- 신뢰도 전용 메타모델 학습 (H7 기각 — 구간폭이 더 낫다)
- 고신뢰 구간 자동 피크 개입 (H9 기각 — 사례가 없다)
- "난조건은 정보 부족 때문"이라는 서사 (H3 기각)
- Data Reliability Layer 를 **학습 기법**으로 쓰는 것 (08 보고서에서 이미 기각)
- 고정 경보 임계 제시 (H10 기각)

**13. 실제 KAMP 데이터로 검증 가능한 것은?**
다중 horizon 예측, 정보 ablation, 난조건 발견, 잠재문맥 안정성, SR 식, 신뢰도 점수·밴드 단조성,
게이트 등급 분포, 비용비-임계 곡선, 정보 한계가치. **위 전부가 이번에 실제 측정되었다.**

**14. 가상공장으로 남겨야 하는 것은?**
설비 단위 전력/ON-OFF 진실값이 필요한 모든 것 — 진짜 NILM 성능, 개별 센서의 정보가치,
스케줄 재배치의 피크 저감 효과, 난조건의 물리적 기전. 결과는 항상 **시뮬레이션 결과**로 표기.

**15. 증거만으로 볼 때 최종 대회 주제는?**

> **"저계측 제조 FEMS 를 위한 신뢰도 게이트형 피크 경보 — 무엇을 예측할 수 있는지가 아니라,
> 언제 믿을 수 없는지를 아는 시스템"**
>
> 구성: `달력+수요이력 예측(L1/L3)` → `CQR 구간폭 = 신뢰도` → `HIGH/MEDIUM/LOW/OOD 밴드` →
> `비용비 기반 경보 임계` → `피크는 자동개입이 아닌 작업자 권고로 라우팅`

선정 근거(차별성이 전부 측정된 사실에서 나온다):
1. 정확도 경쟁을 하지 않는다 — 10 보고서가 달력만으로 90% 가 끝난다는 것을 보였으므로,
   "더 정확한 회귀"는 대회에서 팔 것이 없다. 남은 미개척 축은 **신뢰도와 결정**이다.
2. 신뢰도 레이어가 **공짜**다(H7). 저계측/저비용 환경이라는 문제설정과 방법이 일치한다.
3. **네 개의 기각**을 들고 간다(H3·H4·H7·H9). 심사 항목의 "데이터 이해/진단"과 "영향인자·오차 분석"
   에서 기각 근거는 채택 근거보다 강한 증거다. 특히 H9(고신뢰와 고피크위험의 구조적 반상관)는
   설계를 실제로 바꾼 발견이다.
4. 현장 적용성이 수치로 제시된다: ADVISE 5.9% / 자동화 불가 19.1% / 비용비별 일 경보수.
5. 금액·단위 미확정(09 보고서)을 우회한다 — 비용비 곡선은 KRW 를 발명하지 않아도 정책을 준다.
